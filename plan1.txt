#상대법

상대법 섹션의 좌측 상단에는 (탑, 정글, 미드, 원딜, 서폿) 순으로 래인 선택 아이콘이 있다.
/*그러나 미드를 제외한 나머지 라인은 추후 개발 예정 */

상대법 페이지에는 '암살자', '메이지', '브루저/원딜' 세가지 하위 아티클을 선택할 수 있고, 
각각의 커버 이미지는 ./images  폴더에 있는 'Zed.jpg', 'Zoe.jpg', 'Yone.jpg'로 한다.
각각의 커버 이미지를 클릭할 시 해당 카테고리에 속한 챔피언들의 1:1 비율의 일러스트(Pick창에서 주로활용되는)와 챔피언 명이 나열된다. 
암살자 {카타리나, 제드, 아칼리, 피즈, 르블랑, 나피리, 탈론, 키아나}
메이지 { 아리, 말자하, 빅토르, 멜, 신드라, 라이즈, 제라스, 트위스티드페이트, 럭스, 
오로라, 오리아나, 애니비아, 조이, 베이가, 벡스,  카시오페아, 탈리야, 애니, 아우렐리온솔, 흐웨이, 리산드라, 아지르 }
브루저/원딜 { 사일러스, 요네, 야스오, 갈리오, 에코, 다이애나, 이렐리아, 사이온, 코르키, 제이스, 스몰더, 트리스타나, 아크샨, 로크} 
/*이외에도 더 있을 수 있음*/
챔피언 검색 기능을 지원한다.

해당 챔피언의 일러스트를 클릭할 시 강조효과 애니메이션이 발동되면서 진정한 상대법창으로 넘어간다.

상대법창 가장 위
### Cool down Traking
상대 챔피언의 스킬아이콘(1:1 비율) 4개가 나열되고, 1레벨기준 쿨타임이 아이콘위에 숫자로 적혀있다.
아이콘에 마우스 hover할 시 (재사용대기시간, 소모, 범위, 스킬설명 등이 자세히 나온다.)
### User Comment
유저들이 직접 해당 챔피언을 상대하는 방법을 적는 게시판이다.
(예시: 제드를 상대할 때는 그림자(w)의 쿨타임이 빠졌을 때 약 20초동안 강하게 압박해야한다. 또한 Q가 빠졌을 때 6초간 강하게 압박하는 것이 핵심이다.)
예시와 같이 댓글을 달 수 있고, 댓글 왼쪽에는 작성자의 프로필과 닉네임이 표시된다.  해당 Tip은 좋아요 혹은 싫어요를 다른 사용자로부터 받는다.
Tip은 좋아요 순, 날짜 순, 시즌 별 보기 등으로 정렬할 수 있어야 하므로 메타 데이터가 보관되어야 한다.

사용자가 Tip을 적을 때 Tip중 일부분에 형광펜을 친 후 '아군 챔피언 특정'이라고 한정할 수 있다. 예를 들어 제드에 대한 상대법을 10줄 적었는데, 그 중 3줄은
내가 '트위스티드페이트'일 때만 유효한 상대법이라면 해당 3줄은 형광펜을 친 후 트위스티드페이트를 선택한다. (콤보박스에서 검색하면 챔피언 이름이 나오도록)

사용자는  Tip을 볼 때 Combobox에서 특화 상대법보기에서 아군챔피언을 선택하면, (예를들면 트위스티드페이트) 숨겨져있던 형광펜이 나타나면서 일반적인 경우에서의 제드 상대법이 아닌
트위스티드페이트 vs 제드의 상대법까지 함께 볼 수 있게 된다.
